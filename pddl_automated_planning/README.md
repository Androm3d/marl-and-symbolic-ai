# 🚀 PDDL Automated Planning: Multi-Level Autonomous Mission Planning

A formal **Planning Domain Definition Language (PDDL 2.1)** suite implementing hierarchical autonomous exploration, resource allocation, and sample analysis missions. Developed for the *Artificial Intelligence (IA)* curriculum at **UPC-FIB**.

## 🏛️ Project Architecture & Progressive Extensions

The project implements a progressive progression from basic STRIPS actions to complex numerical fluents and temporal constraints:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          PDDL PROGRESSIVE EXTENSIONS                        │
├───────────────────┬─────────────────────────────────────────────────────────┤
│ 📍 nivel_basico   │ Core STRIPS predicates (Move, Load, Unload, Deliver)   │
│ 🔋 extension1     │ Fuel consumption & dynamic refueling mechanics          │
│ ⏱️ extension2     │ Action durations, scheduling & temporal concurrency     │
│ 🎯 extension3     │ Metric optimization (minimizing total time & fuel)      │
│ ⚡ extension4     │ Dynamic priority constraints & real-time resource locks │
└───────────────────┴─────────────────────────────────────────────────────────┘
```

---

## 🔬 Domain & Problem Model

Each level contains:
1. `domain.pddl`: Action schemas with typed parameters, preconditions, and positive/negative effect lists.
2. `problem.pddl`: Initial world state predicates and conjunctive goal specifications.
3. `generador_problema.java` / `problem_generator.java`: Autonomous Java benchmark generator creating randomized problem instances with scalable object counts.
4. `output-problem.txt`: Verified execution plan traces generated by FF (FastForward) and Metric-FF planners.
